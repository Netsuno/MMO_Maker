# Licences — monde de démonstration P10-4

Ce dossier accompagne le **monde de démonstration temporaire** (fixture de validation).
Il ne constitue pas le contenu final FRoG.

## Graphismes

Les cartes du monde démo n’embarquent **aucun bitmap FRoG**. Elles utilisent des tuiles
procédurales (`TilesetId = 1`, `SrcX` distinct par carte : village / faubourgs / arène).
Les chemins d’icônes et de sprites (`icons/…`, `sprites/…`) sont des identifiants logiques
de catalogue, pas des fichiers repris d’un jeu tiers.

Aucun asset FRoG n’est redistribué ici.

## Code

Le catalogue et l’outil de publication sont du code MMO_Maker (Phase 10), mêmes termes
que le dépôt.

## Crédits

- Cartes, NPCs, quêtes, recettes : fixture P10-4 générée pour la recette bêta.
- Noms : originaux, non copiés d’un titre commercial.
