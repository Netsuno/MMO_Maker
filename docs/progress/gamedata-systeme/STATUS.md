# STATUS — Données de jeu : Système

| Champ | Valeur |
| --- | --- |
| **Chantier** | Paramètres Système (monnaie, groupe, carte, musiques, termes) |
| **Propriétaire** | Netsun |
| **Statut** | Document unique brouillon / publication, catalogue interrupteurs / variables conservé |
| **Protocole** | `FrogWireProtocol.Version` **reste 11** |
| **Tuiles** | TileAsset / TilePack **48×48** |

L’unité monétaire vaut « Or » par défaut et sert de terme Or. Le groupe de départ accepte jusqu’à 4 héros publiés. La carte de départ est un identifiant de carte. Les musiques de titre et de départ reprennent le chemin, le volume et le fondu du BGM de carte. Les termes courts sont HP et MP. Pas de lexique complet, pas d’événements communs.
