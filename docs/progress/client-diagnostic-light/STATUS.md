# STATUS — Panneau diagnostic client (léger)

| Champ | Valeur |
| --- | --- |
| **Chantier** | Overlay diagnostic Frog.Client |
| **Propriétaire** | Netsun |
| **Statut** | Panneau F3, fermé par défaut |
| **Protocole** | `FrogWireProtocol.Version` **reste 11** |
| **Tuiles** | TilePack **48×48**, statut seulement |

F3 affiche ou masque le panneau (Hello, serveur, ping si un battement de cœur a répondu, paquet de tuiles, dernière erreur). Échap ou Fermer le range. Pas de changement de fil ni de format `.frogpack`.
